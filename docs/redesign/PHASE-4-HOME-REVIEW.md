# Phase 4 — Home workspace review

Review `/redesign/home` as the first core-experience checkpoint.

## Purpose

Home is no longer a decorative greeting screen. It becomes a calm daily
orientation point: one intention, a compact task list, visible momentum, and a
clear handoff into Focus.

## Preserved behavior to connect after approval

- Current user greeting and localized clock/date.
- Task query, quick add, completion, steps, and exclusive doing-now selection.
- Existing Pomodoro timer, phase switching, session logging, and categories.

This review surface uses local interaction state only; it does not replace those
existing services or stores. Approval here authorizes the visual and interaction
model, after which the live Home will be connected to the preserved logic.
